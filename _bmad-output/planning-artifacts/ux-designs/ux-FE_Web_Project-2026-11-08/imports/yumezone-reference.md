# Reference Capture: YumeZone (`https://yumezone.live/`)

## Domain & Product Context
- Ad-free anime streaming & manga reading platform with watchlist tracking.

## Extracted Visual & Token DNA
- **Base Surfaces:** Pure pitch-black cinema canvas (`#000000`), elevated dark layers (`#08080A`, `#090909`, `#121212`, `#1F1F23`), translucent glass surfaces (`bg-white/[0.04]`, `bg-white/5`, `backdrop-blur-md`) with hairline borders (`border-white/10`, `border-zinc-900/60`).
- **Foreground & Contrast:** Crisp off-white primary text (`#F0F0F5`), muted zinc secondary copy (`#D4D4D8`, `#A1A1AA`, `#71717A`).
- **CTA & Accent Language:** High-contrast white primary action button (`#FFFFFF` background, `#000000` bold label, soft ambient white glow `0 0 20px rgba(255,255,255,0.15)`), translucent ghost secondary buttons (`bg-white/5 border-white/10`), customizable default sage-teal accent (`#91B8B1`).
- **Typography:** `Inter` sans-serif for UI and bold tight-tracked headlines (`tracking-tight` / `-2px`), paired with `Instrument Serif` italic inline accents for editorial contrast, plus uppercase wide-tracked micro-badges (`10px`, `tracking-widest` / `3px`).
- **Atmosphere & Radii:** Desaturated/grayscale low-opacity hero artwork (`opacity-30 grayscale brightness-50`) bleeding into black gradients; `rounded-xl` (`12px`) buttons/cards and `rounded-full` pill badges; smooth `cubic-bezier(0.16, 1, 0.3, 1)` transitions.
